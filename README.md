# CaPITN

## Overview

This repository contains the implementation of the paper: ***CaPITN: A Causality-Constrained and Enhanced Physics-Informed Transformer Framework for Solving Partial Differential Equations***.

**Status**: The manuscript is currently **Under Review**. No preprint version has been submitted to arXiv at this stage.

Once published, please update your citation to refer to the official journal DOI or conference proceedings.

## Get started

1. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

2. Run the training script:

    ```bash
    python <notebook_name>.ipynb
    ```

3. All training results are saved in the `results/` folder of the corresponding case. You can load the relevant `.pt` files to reproduce the experimental results.
